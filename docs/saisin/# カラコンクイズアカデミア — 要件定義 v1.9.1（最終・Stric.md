## **0\. TL;DR（変更の全体像：一行）**

**マスタ（Google Sheets→CSV）を E(元品番)/I(ブランド:カナ)/J(カラー:カナ)/K(装用期間) の4列で出力し、ファイル名と E/I/J/K が完全一致する素材だけを**自動採用\*\*（非一致は *manual\_fix\_queue*）。すべてのツール（rename／manifest 生成／候補生成）を **G→E** 基準へ切替。**DryRun → 少数テスト → 全量適用 → commit/push**。\*\*

## **1\. v1.9 → v1.9.1 変更履歴（Breaking Changes）**

* **命名キーの切替**：`G(品番)`→`E(元品番)` に変更。

  * **v1.9（従来）**：`key = E|I|J|K`、命名 `G_I_J_K_{lens|samune}.jpg`。

  * **v1.9.1（本変更）**：`key = E|I|J|K`、命名 `E_I_J_K_{lens|samune}.jpg`。

* **厳格一致の再定義**：**E/I/J/K の完全一致**のみを**自動適用**。一致しない候補は **manual\_fix\_queue** に回す（人手対応）。

* **影響範囲**：PowerShell の rename 系、manifest 生成（Python）、候補生成ロジック、ドキュメント／CI テスト一式。

* **不変**：Strict 画像ポリシー（不一致素材は非採用・非表示）、manifest 一元管理、シャーディング、raw→CDN フォールバック、X=レンズ／W=サムネの役割、**Noto Sans JP の適用**。

## **2\. データ仕様（v1.9.1）**

### **2.1 マスタ（109販促データ / `master`）**

* 必須列：**E:元品番**, **I:ブランド(カナ)**, **J:カラー(カナ)**, **K:装用期間**

* 文字コード：`UTF-8 (BOM あり/なしどちらでも)`

* **固有キー**：`key = sanitize(E) + '|' + sanitize(I) + '|' + sanitize(J) + '|' + normalize(K)`

* **命名規則**：`<E>_<I>_<J>_<K>_{lens|samune}.jpg`（拡張子は `.jpg` 固定）

  * 例：`HL001_ｱｲｸﾛｰｾﾞｯﾄ_ちびこっぺぱん_1day_lens.jpg`

* **サニタイズ**（推奨）：全角英数→半角、空白→`_`、`・,、，／/`→`_`、禁則除去、連続 `_` 圧縮、lower 化（期間表記は既定集合へ正規化）。

* **受入条件**：**E/I/J/K** が**先頭4トークン**で完全一致するファイルのみ採用（suffixは `_lens.jpg` / `_samune.jpg` 等で判定）。

  * 解析は **`_` split → 最低4トークン確認 → 先頭4つを E/I/J/K とみなす**。

v1.9 で定義済みの Strict・SSOT(manifest)・シャーディング・フォールバック方針はそのまま継承します。

## **4\. 命名・正規表現・解析ルール**

* **想定ファイル名**：`E_I_J_K_<type>.jpg` (`type` ∈ `lens|samune`)

**正規表現（目安）**：

 ^(?\<E\>\[^\_\]+)\_(?\<I\>\[^\_\]+)\_(?\<J\>\[^\_\]+)\_(?\<K\>\[^\_\]+)\_\[^\_\]+\\.jpe?g$

*   
* **実装指針**：**正規表現より `_` split が堅牢**（先頭4トークン＝E/I/J/K、足りなければ不採用）。

* **非一致処理**：ログに記録し **manual\_fix\_queue**（CSV）へ出力。

画像取得フロー（GAS/フロント）やエラー時のフォールバック概念は v1.9 に従う。

## **6\. 検証（UAT／必須ケース）**

1. **単一行一致**：マスタの特定行(E/I/J/K)に対応する素材が **manifest／suggestion** に入る。

2. **元品番重複**：E が同一でも I/J が異なる素材は **除外**（E/I/J/K 完全一致のみ許容）。

3. **命名不正**：トークン \< 4（`_` 不足）は **除外**。

4. **DryRun で MISSING なし** → **全件移動可能**。

5. **GAS/フロント**：manifest ヒットのみ出題、サムネは任意、Noto Sans JP で表示。
