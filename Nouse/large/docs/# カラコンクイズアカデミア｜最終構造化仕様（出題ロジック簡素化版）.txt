# カラコンクイズアカデミア｜最終構造化仕様（出題ロジック簡素化版）

## 0. このドキュメントの目的

* **“109販促データ（マスター）→クイズ問題”** の道筋を**最小・堅牢**に定義する
* 実装担当が**迷わない**よう、**除外条件**と**誤答抽出**まで**手順化**
* 既存仕様（列定義／W=サムネ, X=レンズ／E/I/J/Kキー）との**整合性を担保**

---

## 1. データ前提（マスター／カテゴリ）

### 1.1 109販促データ（**master**タブ）

* **2行目＝項目（ヘッダ）**、**3行目〜＝データ本体**
* **空白セルが1つでもある行は不採用**（空白行も不採用）
* **必須列**（1始まり / 既存仕様に準拠）

  * **E=元品番**（以降“E”）、**I=ブランド(カナ)**、**J=カラー(カナ)**、**K=装用期間**（複合キー） 
  * **X=レンズ画像URL**（クイズ画面は**X列の画像**を使用。Wは正解フィードバック用） 
  * 参考: P=DIA, Q=G.DIA, R=BC, W=サムネ, AL=コメント（任意） 

### 1.2 109販促データ（**カラーカテゴリ**タブ）

* **B=ブランド(カナ)**、**C=カラー(カナ)**、**F=カラーカテゴリ**（例: `ブラウン,ベージュ` のようなカンマ区切り） 
* **空白セルがあればその行は不採用**（B/C/Fのいずれも必須）

> **キー統一**：画像や集計は **E/I/J/K** を**完全一致**の基準にします（Strict）。ファイル名も `E_I_J_K_{lens|samune}.jpg` に揃える（将来のmanifest/同期でも一貫）。

## 3. 出題ロジック（確定）

### 3.1 フィルタ条件（読み込み時）

**masterタブは3行目から**走査し、下記**すべて満たす**行のみ採用：

1. **E, I, J, K, X がすべて非空**
2. 行全体に**空白セルが残っていない**（必須列に限らず空白があれば除外）
3. **X（レンズ画像URL）が有効**（URL形式・アクセス可の確認は可能な範囲で／不可なら除外）
   　※Wは参考（正解フィードバック用途）で不採用に影響しない。

> **注**：**2行目は項目行**のためデータ対象外。ヘッダの空白有無に依存せず、**列番号で確実に参照**してください（I/J/K/X 等）。

### 3.2 正答の決定

* フィルタ済み集合からランダムに1件を**正答**として選ぶ（**E|I|J|K** を保持）
* 表示に使う画像は **X列（レンズ）**。

### 3.3 カテゴリ照合（“正答の色カテゴリ”の確定）

* **カラーカテゴリ**タブから、**B==I かつ C==J** の行を1件取得（完全一致） 
* その行の **F列** を **`[,，、／/・]`** などで分割 → **{色語}** の集合を得る
  例：`"ブラウン,ベージュ"` → `{"ブラウン","ベージュ"}`

### 3.4 誤答3件の抽出（“色カテゴリに合致”のもの）

* **候補母集団**＝3.1で残った集合から、**正答と異なる**レコードのみ（≠ 同一E|I|J|K）
* **条件**：その候補に対するカテゴリ行（B=I, C=J）が存在し、**F列の色語に {色語} の**いずれか**が含まれる

  * 例：正答のカテゴリに**“ブラウン”**があれば、**“ブラウン”**を含む別商品のカテゴリが対象
* **X列（レンズ画像）が有効**なものだけに限定
* **3件**見つかるまで抽出（ランダム or 安定シャッフル）

#### フォールバック（3件未満のとき）

1. 同カテゴリが不足 → **同ブランド(I一致)** で **J≠正答J** かつ **X有り**
2. それでも不足 → **全ブランド**から **X有り** で **E|I|J|K ≠ 正答**
   ※常に**同一商品は除外**（E|I|J|K完全一致はNG）。**重複は除外**。

> “カテゴリによる誤答選抜”の導入により、**見た目が紛らわしい色味**で誤答が揃うようになります（同一商品定義は E/I/J/K で一貫）。

## 5. 疑似コード（GAS想定・そのまま下敷きにできます）

### 5.1 共通ユーティリティ

```js
// 空白系の判定（null/undefined/空文字/空白のみ）
const isBlank = v => v === null || v === undefined || String(v).trim() === "";

// 文字列 → 色語配列（カンマや各種区切りを許容）
const splitColors = s =>
  String(s || "")
    .split(/[,\u3001\uFF0C\u30FB\/／|]+/)
    .map(x => x.trim())
    .filter(x => x);

// E|I|J|K の複合キー
const ck = r => [r.E, r.I, r.J, r.K].join("|");
```

### 5.2 マスター読み込み（**3行目から**＋**空白除外**）

```js
function readMaster_(sh) {
  // 2行目=項目、3行目〜=データ
  const values = sh.getRange(3, 1, sh.getLastRow()-2, sh.getLastColumn()).getValues();
  const COL = { // 1始まり → 0始まりへ
    E: 4, I: 8, J: 9, K: 10, X: 23, P: 15, Q: 16, R: 17, W: 22, AL: 37
  };
  const rows = [];
  for (const v of values) {
    // 任意列も含め**空白セルがあれば不採用**
    if (v.some(isBlank)) continue;
    const r = {
      E: v[COL.E], I: v[COL.I], J: v[COL.J], K: v[COL.K],
      X: v[COL.X], P: v[COL.P], Q: v[COL.Q], R: v[COL.R],
      W: v[COL.W], AL: v[COL.AL]
    };
    if ([r.E, r.I, r.J, r.K, r.X].some(isBlank)) continue; // 必須欠落
    rows.push(r);
  }
  return rows;
}
```

> **W=サムネ／X=レンズ**の役割と、**Xをクイズで使う**前提は既定仕様のとおり。

### 5.3 カラーカテゴリ読み込み（**空白除外**）

```js
function readCategories_(sh) {
  const values = sh.getDataRange().getValues(); // 必要なら3行目以降に調整
  // 例：ヘッダ1~2行があるなら 3行目以降に変更
  const B = 1, C = 2, F = 5; // 0始まり
  const map = new Map(); // key: I|J → 色語配列
  for (let i = 2; i < values.length; i++) { // 3行目〜
    const v = values[i];
    if (v.some(isBlank)) continue; // 空白セルがあれば除外
    const I = String(v[B]).trim();
    const J = String(v[C]).trim();
    const colors = splitColors(v[F]);
    if (!I || !J || colors.length === 0) continue;
    map.set(`${I}|${J}`, colors);
  }
  return map;
}
```

> **B=ブランド(カナ)、C=カラー(カナ)、F=カテゴリ**を用いる前提は既存要件と一致。

### 5.4 誤答抽出ロジック

```js
function pickWrongAnswers_(correct, pool, catMap, n = 3) {
  const key = `${correct.I}|${correct.J}`;
  const colorWords = catMap.get(key) || [];
  const corrCk = ck(correct);

  // 1) 色カテゴリ一致の候補（同一商品除外、Xあり）
  let cands = pool.filter(r => {
    if (ck(r) === corrCk) return false;
    const k = `${r.I}|${r.J}`;
    const c = catMap.get(k) || [];
    return c.length && colorWords.some(w => c.includes(w)) && !isBlank(r.X);
  });

  // シャッフル（安定シャッフルでも可）
  cands = cands.sort(() => Math.random() - 0.5);

  // 2) 足りなければフォールバック
  const picked = [];
  for (const r of cands) { if (picked.length < n) picked.push(r); }

  if (picked.length < n) {
    const sameBrand = pool.filter(r =>
      ck(r) !== corrCk && r.I === correct.I && r.J !== correct.J && !isBlank(r.X)
    );
    for (const r of sameBrand) { if (picked.length < n && !picked.includes(r)) picked.push(r); }
  }
  if (picked.length < n) {
    const any = pool.filter(r => ck(r) !== corrCk && !isBlank(r.X));
    for (const r of any) { if (picked.length < n && !picked.includes(r)) picked.push(r); }
  }

  return picked.slice(0, n);
}
```

### 5.5 1問の生成

```js
function makeQuestion_(correct, wrongs) {
  const options = [
    { label: `${correct.I} / ${correct.J}`, isCorrect: true },
    ...wrongs.map(w => ({ label: `${w.I} / ${w.J}`, isCorrect: false }))
  ].sort(() => Math.random() - 0.5);

  return {
    qid: `CK:${ck(correct)}`,
    image: correct.X,              // レンズ画像(X列)
    specs: { DIA: correct.P, G_DIA: correct.Q, BC: correct.R }, // 任意
    correct: { E: correct.E, I: correct.I, J: correct.J, K: correct.K },
    options
  };
}
```

## 7. 品質ゲート（必ず落とすチェック）

* **読み込み時**：

  * 行内に**空白セルが1つでもある** → **除外**
  * **E/I/J/K/X** の**いずれか空** → **除外**
  * **カテゴリ側**：B/C/Fの**いずれか空** → **除外**
* **誤答選抜**：

  * **同一商品（E|I|J|K完全一致）は禁止**
  * **画像Xが無い候補は不採用**
  * **重複ラベル**や**同じ(I/J)の重複**は除外（違う候補に置換）

## 8. テスト観点（現場チェック用）

1. **行スキップ**：2行目（項目）は**必ず除外**／3行目〜のみ対象
2. **空白除外**：E/I/J/K/Xのいずれか空の行が一切通らない
3. **画像**：正答・誤答とも**X列画像**で表示される（Wは正解時のみ） 
4. **カテゴリ連動**：正答のF列色語に**1語以上合致**する誤答が**3件**揃う
5. **フォールバック**：3件に満たないケースで**補充**される
6. **同一商品除外**：E/I/J/K完全一致が混ざらない（Strict） 
7. **API整合**：ランキング/成績のキーと**E|I|J|Kで一致**（将来の集計強化に備える）
