# 🔧 依頼: HL001（カラコンクイズ）に v1.7 変更を実装して

あなたは熟練のフルスタックエンジニアです。以下の 4 点を **Google Apps Script（GAS）＋既存フロント**に実装し、テストまで完了してください。

## 変更要約（実装対象）

1. **QUIZ\_HISTORY に列追加**
   `elapsedSec`（0–200秒）／`timeBonusPt`（0–200pt）／`totalPoints`（0–300pt）を確定列として追加・保存。

* 仕様根拠：最終正答率は **生正答率 − (ヒント×3%) − (タイムアウト×10%)** を維持（下限0%）。
* タイムボーナスは 10問=200sec の **残秒数をそのままポイント**として加点（0–200）。
* 参考指標 `totalPoints = ROUND(finalAccuracy) + timeBonusPt`（最大300）も記録。

2. **出題ロジックに canonicalKey を導入**
   「**ブランド名カナ＋カラー名カナ**」の正規化キーで同一判定し、**装用期間が異なるだけのカラコンも同一**とみなす。1問内の選択肢は **canonicalKey 重複禁止**。

* 仕様根拠：同一商品判定は *ブランド名カナ + カラー名カナ*（v1.5）を拡張、装用期間差は同一扱い。

3. **ランキング集計の拡張**
   期間に **累計（ALL）** を追加。集計軸に **総合（合計）／平均** トグルを追加。

* 公式順位は引き続き **最終正答率** ベース（同率時は `sumTimeBonus` → `avgTime`）。
* 参考として `sumTotalPoints` による並び替えも可能にする。

4. **ダッシュボード UI の拡張（Noto Sans JP 適用）**
   ランキングタブ：**Day / Week / Month / 累計** を実装。指標トグル：**総合 / 平均**。既存の **店舗／勤務形態／権限** フィルタは維持。UIトーンは現行デモに準拠し、**フォントは Noto Sans JP** を明示的に読み込み・適用すること。 &#x20;

```js
function migrate_add_v16_history_columns() {
  const sh = getHistorySheet_(); // 実装は DataAccess.gs のユーティリティを利用
  const header = sh.getRange(1,1,1,sh.getLastColumn()).getValues()[0];
  const need = ['finalAccuracy','elapsedSec','timeBonusPt','totalPoints'];
  const miss = need.filter(n => !header.includes(n));
  if (miss.length) {
    sh.insertColumnsAfter(sh.getLastColumn(), miss.length);
    sh.getRange(1, sh.getLastColumn()-miss.length+1, 1, miss.length).setValues([miss]);
  }
  // 既存行の欠損は 0 埋め or 再計算（finalAccuracy は可能なら再計算）
}
```

### 2) 記録時のメトリクス確定（最終正答率＋タイムボーナス）

**Contracts/Logic（適切な層）** にユーティリティを追加：

```js
function computeFinalAccuracy_(base, hints, timeouts) {
  return Math.max(0, base - 3*hints - 10*timeouts); // v1.5 仕様準拠（下限0） :contentReference[oaicite:9]{index=9}
}
function clamp_(v, lo, hi){ return Math.min(hi, Math.max(lo, v)); }
function computeTimeBonus_(elapsedSec) {
  // 10問=200秒、残秒がそのままボーナス
  const e = clamp_(Math.round(elapsedSec), 0, 200);
  return 200 - e; // 0..200
}
function computeTotalPoints_(finalAcc, timeBonusPt) {
  return Math.round(finalAcc) + timeBonusPt; // 0..300（参考）
}
```

**記録処理**（例：`AuthRank.gs` の保存関数）で新列を確定保持：

```js
function saveSession_(rec) {
```

### 3) 出題の重複禁止（装用期間差を同一扱い）

**QuizLogic.gs** に正規化関数と canonicalKey を追加：

```js
function normalizeKana_(s) {
  if (!s) return '';
  return s.toString()
    .trim()
    .replace(/[ーｰ—‐\-]/g, 'ー')     // 長音・ダッシュ統一
    .replace(/[・･\s]+/g, '')        // 中点・空白除去
    .replace(/[Ａ-Ｚａ-ｚ０-９]/g, c => String.fromCharCode(c.charCodeAt(0)-0xFEE0))
    .toLowerCase();
}
function canonicalKey_(brandKana, colorKana) {
  return normalizeKana_(brandKana) + '|' + normalizeKana_(colorKana);
  // ※装用期間はキーに含めない＝期間違いも同一カラコン扱い（v1.6） :contentReference[oaicite:10]{index=10}
}
```

**選択肢生成**で 4 択内の canonicalKey 重複を禁止：

```js
function buildQuestion_(correct, distractorPool) {
  const used = new Set([canonicalKey_(correct.brandKana, correct.colorKana)]);
  const opts = [correct];
  for (const cand of shuffle_(distractorPool)) {
    const key = canonicalKey_(cand.brandKana, cand.colorKana);
    if (!used.has(key)) { opts.push(cand); used.add(key); }
    if (opts.length === 4) break;
  }
  if (opts.length < 4) return null; // 不足時は再抽選
  return shuffle_(opts);
}
```

> 参照：同一商品判定は「ブランド名カナ＋カラー名カナ」。装用期間差も同一扱い／1問内重複禁止。

### 4) ランキング集計（Day/Week/Month/All × 合計/平均）

**RankingsSnapshot.gs**（新規）：

```js
function rebuildSnapshots_v16() {
  const hist = readHistory_(); // 直近90日＋累計
  const rows = hist.map(h => ({
    userId: h.userId,
    store: h.store, role: h.role, emp: h.employmentType,
    day: Utilities.formatDate(h.endedAt, Session.getScriptTimeZone(), 'yyyy-MM-dd'),
    week: getIsoWeekKey_(h.endedAt),    // 例: 2025-39
    month: Utilities.formatDate(h.endedAt, Session.getScriptTimeZone(), 'yyyy-MM'),
    final: h.finalAccuracy,
    time: h.elapsedSec,
    tBonus: h.timeBonusPt,
    tPoints: h.totalPoints
  }));
  writeAgg_('day',   aggregate_(rows, r => r.day));
  writeAgg_('week',  aggregate_(rows, r => r.week));
  writeAgg_('month', aggregate_(rows, r => r.month));
  writeAgg_('all',   aggregate_(rows, _ => 'ALL'));  // ★累計
}
function aggregate_(rows, keyFn){
  const map = {};
  for (const r of rows) {
    const key = JSON.stringify([keyFn(r), r.userId, r.store, r.role, r.emp]);
    (map[key] ||= { plays:0, sumFinal:0, maxFinal:0, sumTime:0, sumTBonus:0, sumTPoints:0, period: keyFn(r), userId:r.userId, store:r.store, role:r.role, emp:r.emp });
    const m = map[key];
    m.plays++; m.sumFinal += r.final; m.maxFinal = Math.max(m.maxFinal, r.final);
    m.sumTime += r.time; m.sumTBonus += r.tBonus; m.sumTPoints += r.tPoints;
  }
  return Object.values(map).map(m => ({
    periodKey: m.period,
    userId: m.userId, store:m.store, role:m.role, emp:m.emp,
    plays: m.plays,
    avgFinalAcc: m.sumFinal / m.plays,
    maxFinalAcc: m.maxFinal,
    sumFinalAcc: m.sumFinal,
    avgTime: m.sumTime / m.plays,
    sumTimeBonus: m.sumTBonus,
    sumTotalPoints: m.sumTPoints
  }));
}
```

**並び替え規則（公式/参考）**：

* 公式：`avgFinalAcc DESC, sumTimeBonus DESC, avgTime ASC, updatedAt DESC`
* 参考：`sumTotalPoints DESC, avgFinalAcc DESC, avgTime ASC`

## テスト観点

* **列追加**：`finalAccuracy / elapsedSec / timeBonusPt / totalPoints` が新規セッション保存時に必ず埋まる。既存行は 0 または再計算で補填。
